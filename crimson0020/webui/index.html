CRIMSON DESERT LOCALIZATION BUILDER

Dữ liệu nguồn

Thiết lập các package nguồn dùng xuyên suốt quá trình localization.

SOURCE

Các công cụ Unpack, Repack và Font sử dụng lại những đường dẫn này.

Unpack

Giải nén localization package thành dữ liệu JSON dễ đọc và chỉnh sửa.

PACKAGE → JSON

Output mặc định được giữ riêng để không ghi đè dữ liệu nguồn.

Repack

Ánh xạ bản dịch bằng marker + key và dựng lại toàn bộ PALOC an toàn.

JSON → PACKAGE

Package đầu ra được xác minh lại trước khi dùng cho bước Install.

Auto Translate

Ba bước rõ ràng: tách câu cần dịch, dịch hết phần còn thiếu, rồi kiểm tra và ghép vào JSON chính.

COMPARE → TRANSLATE → MERGE

1 Tạo file chỉ gồm câu cần dịch

So sánh theo marker + key. File tạo ra chỉ có câu mới và câu có nội dung nguồn đã thay đổi; không chứa các câu không đổi hoặc toàn bộ catalog.

2 Dịch phần còn thiếu

Chọn file cần dịch. Nếu một phản hồi bị lỗi, tool cô lập dòng lỗi, lưu các dòng đã xong và tiếp tục; bạn có thể đổi dịch vụ rồi chạy tiếp từ checkpoint.

3 Kiểm tra, sửa cấu trúc và ghép

Chọn file câu đã dịch. Tool giữ các bản dịch cũ còn khớp, kiểm tra với JSON nguồn mới và file mẫu từ bước 1, rồi tạo JSON đầy đủ dùng cho Repack.

Dịch xong file ở bước 2 rồi kiểm tra cấu trúc.

File lớn đầy đủ chỉ được tạo ở bước 3. Nếu dịch vụ hiện tại chậm hoặc lỗi, bạn có thể đổi dịch vụ và tiếp tục từ phần đã lưu.

Font

Quản lý riêng package font 0012 để hỗ trợ đầy đủ ký tự tiếng Việt.

0012 PACKAGE

Font được tách khỏi localization để dễ kiểm soát và thay thế.

Install

Cài package Việt Hóa đã build vào game, kèm backup và xác minh metadata.

MOD → GAME

Tool tạo backup riêng trước khi thay đổi package và metadata game.

Uninstall / Restore

Gỡ bản dịch và phục hồi đúng dữ liệu từ lần Install gần nhất.

RESTORE

Restore chỉ dùng backup hợp lệ đã được chính tool tạo ra.
